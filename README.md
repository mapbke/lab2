# Лабораторная работа №2 — Создание запросов

**СУБД:** PostgreSQL 17  
**Среда:** pgAdmin 4  
**Вариант:** 6  
**Предметная область:** склады и размещение товаров

Работа выполнена на основе структуры БД из [лабораторной работы №1](https://github.com/mapbke/lab1). В одном SQL-файле находятся создание учебных таблиц, исходные данные и все семь заданий.

## Файл работы

**[lab2.sql](lab2.sql)** — полный SQL-скрипт для запуска и проверки лабораторной.

Дополнительные SQL-файлы и предварительное выполнение первой лабораторной не требуются.

## Порядок выполнения

1. Открыть **pgAdmin 4** и подключиться к PostgreSQL.
2. Выбрать существующую базу данных (например, `warehouse_lab_v6`) и открыть **Query Tool**.
3. Загрузить файл `lab2.sql` через **Open File**.
4. Выполнить весь скрипт клавишей **F5**.
5. Для просмотра результата конкретного `SELECT` выделить его текст и нажать **F5**. Пункты 3–6 выполняются последовательно, поскольку они изменяют одну рабочую таблицу.

Скрипт создаёт схему `lab2_demo` и таблицы `lab2_demo.warehouses`, `lab2_demo.placements`, `lab2_demo.lab2_warehouses`. При повторном запуске учебные таблицы пересоздаются. Таблицы из первой лабораторной в схеме `public` не затрагиваются.

## Выполненные задания

| № | Задание | Применяемые команды |
|---|---|---|
| 1 | Найти номера складов, которые не получали товары в сентябре | `SELECT`, `NOT EXISTS`, `EXTRACT` |
| 2 | Вывести склады Москвы, где нет заведующего | `SELECT`, `ILIKE`, `IS NULL` |
| 3 | Создать новую таблицу по результатам первого запроса | `CREATE TABLE AS SELECT` |
| 4 | Добавить в неё склады, расположенные вне Москвы | `INSERT INTO ... SELECT`, `NOT EXISTS` |
| 5 | Увеличить вместимость в три раза для складов с чётными номерами | `UPDATE` |
| 6 | Удалить из новой таблицы склады без заведующего | `DELETE` |
| 7 | Рассчитать общий вес отгрузок за 2008 год по каждому складу | `SUM`, `GROUP BY`, `LEFT JOIN` |

## Проверка результатов

В файле используются учебные записи: 12 складов и 14 записей о размещении товаров. Добавлены записи для проверки условий о вакантном заведующем и отгрузках 2008 года.

- **Задание 1:** номера складов `5, 7, 8, 9, 10, 11, 12`.
- **Задание 2:** склад `11` (Москва, заведующий не указан).
- **Задания 3–6:** результат изменения рабочей таблицы выводится отдельным `SELECT` после пункта 6.
- **Задание 7:** ненулевой вес у складов `1` (50,50 кг), `4` (125,75 кг), `7` (35,25 кг) и `11` (44,00 кг). Для остальных складов выводится 0.

В первом задании сентябрь рассматривается независимо от года, поскольку в формулировке не указан конкретный год. В седьмом задании учитываются записи по дате отгрузки с 1 января по 31 декабря 2008 года.

**Примечание:** при повторной проверке заданий 3–6 рекомендуется повторно выполнить скрипт с начала, чтобы получить исходное состояние учебных таблиц.
